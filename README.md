# 📊 Sales Dashboard (Power BI)

An interactive dashboard built in **Power BI** to visualize sales performance by **month**, **region**, and **category** using the `sales.csv` dataset.

## 🔧 Tools Used
- Power BI
- Dataset: Superstore-style `sales.csv`

## 📈 Features
- Line Chart: Sales over time
- Bar Chart: Sales by region
- Donut Chart: Sales by category
- Region/category slicer for filtering

## 🧠 Key Insights
- 🏆 **West** region had highest sales: \$710K+
- 💻 **Technology** was top-selling category: \$827K+
- 📈 **Nov 2018** saw peak sales: \$117K+

## 📁 Files
- `sales_dashboard.pbix`: Power BI file
- `sales.csv`: Source data
- `insights.txt`: Summary insights

## 🚀 How to Use
Open `sales_dashboard.pbix` in Power BI Desktop and explore the visuals interactively.
